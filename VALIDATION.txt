Recommended pre-production checklist: set a long random API_ACCESS_TOKEN, DIAGNOSTICS_PASSWORD and SESSION_ENCRYPTION_KEY; configure GOOGLE_CLIENT_ID and provider credentials; verify HTTPS/cookie settings and OAuth callback URLs; set upload storage/retention limits; review each optional upstream project's license and security before deployment.
